# Локальный справочник географии

`CityDirectory` читает `data/cities.json.gz` в память один раз на процесс.
Он не импортирует движок, адаптеры или HTTP-клиент и не обновляет данные через сеть.
В API передаются только название города, регион и путь; GeoNames ID и ID источников в бриф не попадают.

Данные: [GeoNames](https://www.geonames.org/), лицензия
[Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
Снимок загружен 08.10.2026. Исходный набор `cities500` включает населённые пункты
с населением более 500 человек либо административные центры до уровня PPLA4.
Выбраны 32 страны из `countries.py`, русские и английские альтернативные названия
без отметок historic/colloquial; регионы первого уровня взяты из `admin1CodesASCII`.
Предпочтение отдаётся русскому названию, если оно есть. Отсутствующие переводы не выдумываются.
Полнота и актуальность названий ограничены исходными данными.

Это производный набор: отфильтрованы страны, выбраны подписи, удалены внешние ID,
оставлены население для сортировки и алиасы для поиска. Записи с совпадающими названием
и регионом объединяются при выдаче, поскольку бриф пока не различает их точнее региона.
Формат строки: `[country, name, region, population, aliases]`.
Метаданные, URL и SHA-256 исходников находятся в `data/metadata.json`.

Для обновления явно скачать три файла из `metadata.json` в отдельный каталог и выполнить из корня:

```sh
.venv/bin/python -m scripts.build_geography /path/to/geonames --downloaded-on 2026-10-08
```

Указать фактическую дату загрузки новых исходников. При одинаковых исходных файлах снимок
детерминирован; скрипт не скачивает файлы. Проверить изменения данных и тесты до публикации.

При сопоставлении для HH регион проверяется по пути и уточнению названия. Если административные
подписи отличаются, неуточнённое имя принимается лишь при единственном совпадении в обоих
справочниках и существовании выбранной пары город/регион локально. Одноимённые города не угадываются.
В фильтрах неизвестный регион одноимённого города остаётся непроверенным, в том числе для исключений.
