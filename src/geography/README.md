# Локальный справочник географии

> **Одна версия, одна правда.** Каждый источник справочных данных (Unicode CLDR, GeoNames) присутствует
> в репозитории ровно в одной версии; все производные файлы пересобираются из неё вместе, версия и SHA-256
> записываются в метаданные, устаревшие копии удаляются. Бриф и факты вакансий разбираются одним объектом
> справочника. Решение пользователя от 03.11.2026; см. `docs/vacancy-facts-plan.md` §10.

Единственная точка доступа — `GeographyCatalog` (`catalog.py`): один экземпляр на процесс
(`default_catalog()`), `app.py` передаёт его сервисам брифа и API, источникам и обогащению.
Внутри — два источника, каждый в одной версии:

| Файл | Источник | Что даёт |
|---|---|---|
| `data/cldr.json.gz` | Unicode CLDR 49 | названия 249 стран в 463 локалях, альтернативные названия, 35 групп (M49, `EU`, `EZ`…) с составом |
| `data/cities.sqlite` | GeoNames `cities15000` | города, их названия на всех языках, регионы первого уровня |

SQLite открывается с `mode=ro`; внешние запросы, распаковка при запуске и копии не нужны.
Пользовательская база `search.sqlite` хранится отдельно.

## Данные и языки

Снимок GeoNames `cities15000`: 34 139 населённых пунктов в 243 ISO-территориях.
21 запись исходного набора исключена из-за неназначенных ISO-кодов стран.
Набор включает города с населением более 15 000 человек и административные центры;
он не покрывает все населённые пункты мира.
Все имеющиеся языковые алиасы включены без ограничения RU/EN. Исторические и разговорные
написания доступны, но при равном совпадении современные имеют приоритет.
Ссылки, почтовые и транспортные коды не считаются названиями города.

`cldr.json.gz` содержит названия всех 249 назначенных ISO-кодов из Unicode CLDR 49
для 463 локалей с полным покрытием, альтернативные названия (`US-alt-short` «США», `TR-alt-variant` «Turkey»)
и группы территорий с составом из `territoryContainment`. По умолчанию используется `en`; явный `locale`
меняет только подписи стран. Язык браузера и `Accept-Language` не учитываются.
Неподдерживаемая локаль получает `422`.

Источники: [GeoNames](https://download.geonames.org/export/dump/),
[лицензия CC BY 4.0](https://creativecommons.org/licenses/by/4.0/),
[Unicode CLDR](https://cldr.unicode.org/), [лицензия Unicode](https://www.unicode.org/license.txt).
URL и SHA-256 исходников GeoNames — в таблице `metadata` SQLite; версия CLDR, URL пакетов и SHA-256 — в `metadata` `cldr.json.gz`.

## Выбор города

`GET /api/v1/geography/countries` возвращает коды и локализованные названия стран.
`GET /api/v1/geography/cities?country=RU&text=санкт` возвращает до 20 разных GeoNames ID:
полное совпавшее название `name`, неизменное `ascii_name`, страну, регион и путь.
Точное совпадение идёт первым; остальные результаты сортируются по населению.
Поиск не зависит от регистра, нормализует Unicode, сохраняет диакритику и не исправляет опечатки.

В новых и обновляемых брифах обязательны 1–5 мест поиска. Город — одно место;
явный вариант «Вся страна — без города» — тоже одно место. Для всей страны передаются
`country` и `scope=country`, поля города/региона запрещены. Сервер получает английское
название страны из CLDR. Пустой ввод без явного выбора страны остаётся ошибкой.
Клиент передаёт `country`, `geoname_id` и `city_display_name` из подсказки.
Сервер проверяет их соответствие и сохраняет `city` из GeoNames `asciiname`,
`country_name_en` из английского CLDR, ID и отдельную местную подпись.
Например: `RU`, `Russia`, `524901`, `Moscow`, `Москва`.
У каждого города свои `minimum_work_format` и `relocation_support`.
В форме города с одинаковыми страной и условиями объединены в блок; лимит 5 общий.
В одном блоке выбираются либо города, либо вся страна.
Блоки — альтернативы, формат и релокация проверяются вместе с соответствующим местом.
Старые общие значения условий при сохранении переносятся в места.
Старые брифы и история читаются без перезаписи; перед изменением или запуском старого
брифа пользователь должен заново подтвердить города.

## Граница с обработкой вакансий

ID источника определяется адаптером, а не справочником подсказок. Для HH используется
доступное русское название выбранного ID, при отсутствии — его ASCII-имя.
При сравнении структурированных полей вакансии проверяются алиасы и известные регионы.
Противоречащий известный регион означает несовпадение. Несколько одноимённых городов
в одном регионе остаются неоднозначными; отсутствие города в `cities15000` — неизвестный результат.

Подписи из данных вакансий разбираются тем же объектом: `country` (ISO-код или название на любом языке
CLDR), `group`, `group_countries`, `city`, `region` (GeoNames). Неоднозначность или отсутствие — «неизвестно»,
без выбора по населению или первому совпадению. Сравниваются только города, подтверждённые в брифе (`geoname_id`).
Прежние `CityDirectory`, `cities.json.gz` (`cities500`, 32 страны) и ручной `COUNTRIES` удалены 03.11.2026.

## Пересборка

Сборщики принимают локальные исходники и ничего не скачивают. Обе части пересобираются из одной версии
своего источника; другие копии этих данных в репозитории не допускаются.

```sh
.venv/bin/python scripts/build_cldr.py /path/to/cldr-localenames-full /path/to/cldr-core
.venv/bin/python scripts/build_geography.py /path/to/geonames
```

CLDR: npm-пакеты `cldr-localenames-full` и `cldr-core` одной версии (сборщик проверяет совпадение версий).
GeoNames: `cities15000.zip`, `alternateNamesV2.zip`, `admin1CodesASCII.txt`.
Назначенные коды задаёт `data/iso3166.json`; другой снимок можно передать через `--iso`.
Затем необходимо пересобрать wheel через `scripts/build_plugin.py`.
