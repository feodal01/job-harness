    Пожеланиене совпало — «Может быть подходит»
    Сравниваем с верхней границей вилки, без пересчёта валют и налогов. Вакансии без зарплаты не скрываются.
    Сравниваем с требованием вакансии: «от 1 года» подходит, «от 3 лет» — нет.
