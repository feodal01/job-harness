Источники, фильтры и остальные условия

Источники
Без города — поиск по всей выбранной стране.
Места — жёсткое условие. Можно добавить несколько. Для удалёнки по стране город не ограничивает поиск; удалёнка по миру подходит, если ваша страна явно не исключена. Более свободный формат тоже подходит: например, при выборе гибрида подходит и удалёнка. Работодатель оплачивает или помогает организовать переезд. Само наличие офиса за рубежом этого не подтверждает.

Зарплата, опыт и другие условия

Достаточно, чтобы верхняя граница вилки допускала эту сумму. Вакансии без зарплаты остаются подходящими. Валюты, периоды и налоги не пересчитываются.
Занятость
Расширяет поиск: формат, опыт, занятость и другие мягкие условия проверяются после получения вакансий. Несовпадения попадают в «Может быть подходит». Поиск может потребовать больше запросов. По умолчанию выключен; режим фиксируется на весь запуск.
