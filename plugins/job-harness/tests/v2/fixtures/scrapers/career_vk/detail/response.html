VK ID — центральный провайдер идентификации, аутентификации и авторизации. Мы реализуем единый аккаунт для сервисов VK и обеспечиваем сохранность данных миллионов пользователей.

Задачи

  • Мобильное тестирование (iOS, Android): функциональные проверки, работа с логами (Logcat, Xcode), тестирование нестабильной сети, push-уведомлений и deep links
  • Тестирование API и серверной логики: работа с REST API (Postman, curl), проверка прав доступа, обработка ошибок, анализ ответов
  • Интеграционное и регрессионное тестирование: проверка взаимодействия сервисов, проведение smoke и regression перед релизами
  • Работа с данными: верификация через SQL (SELECT, JOIN, фильтрация), контроль корректности данных и миграций
  • Документация и дефекты: поддержка тест-кейсов в актуальном состоянии, оформление баг-репортов (логи, трейсы, скриншоты)
  • Командная работа: участие в Agile-процессах (груминги, дейли, ретро), уточнение требований с командой
  • Тестирование интеграций auth-сервиса: работа с внешними провайдерами (соцсети, SMS) и внутренними микросервисами

Требования

  • От двух лет коммерческого опыта тестирования (Web/Mobile/Backend)
  • Уверенные знания теории: виды тестирования, техники тест-дизайна
  • Опыт тестирования REST API (HTTP-методы, статусы, заголовки; Postman, Swagger/OpenAPI)
  • Понимание аутентификации и авторизации (OAuth 2.0, JWT,токены, роли)
  • Навыки работы с логами и сетевыми инструментами (Charles/Proxyman), трассировка запросов
  • Базовые знания SQL (SELECT, JOIN, фильтрация)
  • Опыт мобильного тестирования (iOS, Android), понимание особенностей платформ, сбор логов
  • Опты работы с баг-трекингом и документацией (Jira, Confluence и прочее), написание качественных баг-репортов

Будет плюсом

Базовые знания автоматизации тестирования: чтение и валидация автотестов, написание простых скриптов.
