## Общее правило: «да», «возможно», «нет» (05.11.2026)

У вакансии может быть несколько **версий** одного факта: из ленты, из карточки, из структуры источника, из
текста описания. Версии не ранжируются. Ни свежесть, ни метод (`structured` или `text`), ни выгода для
кандидата не делают одну из них правдой.

Каждая версия отдельно отвечает на условие брифа: «да», «нет» или «неизвестно». «Неизвестно» значит, что версию
не удалось прочитать или сопоставить. Это отсутствие сведений, а не противоречие.

| Ответы версий (без «неизвестно») | Вердикт условия |
|---|---|
| все «да» | **да** |
| все «нет» | **нет** |
| есть и «да», и «нет» | **возможно** |
| ответов нет | **неизвестно** |

- **Альтернативы — не версии.** Если работодатель перечисляет варианты через «или», например «офис в Москве или
  удалёнка по РФ», это несколько мест одной правды. Условие проходит, если подходит хотя бы одно место.
  Правило версий применяется к каждому такому варианту отдельно.
- **Вывод из сказанного — версия, предположение при молчании — нет.**
  - Если источник что-то сказал, а мы уточнили смысл по умолчанию (HH «Удалённо» → удалёнка в стране
    публикации), это версия наравне с явными значениями.
  - Если никто ничего не сказал и мы подставили значение (занятость → найм, полная), это не версия. Как только
    появляется любое сведение, предположение отбрасывается.
- **Разные фразы одного текста — разные версии.**
- **Молчание обычно — «неизвестно».** Исключения: релокация — при прочитанном полном тексте молчание значит «нет»
  ([relocation-check.md](relocation-check.md)); занятость — молчание значит найм и полная нагрузка
  ([employment-check.md](employment-check.md)); профроль — «не понять» у классификатора даёт «Может быть
  подходит» ([profession-role-check.md](profession-role-check.md)).
- **Изменение во времени — тоже не версия.** Если тот же этап (лента или карточка) позже показывает другое
  значение, берётся новое.

| Вердикт | Жёсткое условие | Мягкое условие |
|---|---|---|
| да | проходит | проходит |
| возможно | «Подходит» с меткой «не проверено» и обеими версиями в причине | то же |
| неизвестно | «Подходит» с меткой «не проверено» | то же |
| нет | вакансия отклонена | «Может быть подходит» |

Зарплата — частный случай правила. Минимум кандидата ниже P подходит по всем версиям, поэтому «да». Минимум
выше E не подходит ни по одной, поэтому «нет». Минимум между ними — «возможно».
