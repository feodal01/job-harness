# Исключённые компании: проверка списка исключений

Статус: согласовано 06.11.2026. Общее правило вердиктов — в [README](README.md).

## Условие в брифе

Список названий компаний (до 50), свободный ввод. Вакансия компании из списка отклоняется: условие
**жёсткое** — пользователь явно не хочет видеть эту компанию.

## Нормализация названий

И запись брифа, и название компании вакансии приводятся одинаково:

1. Регистр убирается (`casefold`).
2. Кавычки всех видов («», "", '', „“) и знаки препинания (`.`, `,`, `-`, `&`) убираются, пробелы схлопываются.
3. Правовая форма убирается: ООО, АО, ПАО, ИП, LLC, Ltd, Inc, GmbH, S.A. и т. д. Список сокращений — из
   справочника ISO 20275 (ELF, открытый CSV от GLEIF), не ручная таблица. Форма убирается только целым словом
   в начале или в конце названия.

```
«ООО «Яндекс»»      → яндекс
"Yandex LLC"        → yandex
Альфа-Банк, АО      → альфабанк
Сбер Бизнес         → сбер бизнес
```

## Сравнение: начало названия посимвольно

Исключение срабатывает, если нормализованное название компании **начинается** с нормализованной записи брифа
(решение 06.11.2026). Пробелы при сравнении не учитываются: «Сбер Бизнес» и «СберБизнес» сравниваются одинаково.

```
запись «Сбер»  → исключает: Сбербанк, СберМаркет, Сбер Бизнес, ПАО «Сбербанк»
               → не исключает: Тинькофф, Банк Сбер (не с начала)
```

Это решение первой версии: сперва нормализация, затем посимвольный поиск от начала названия.

**Ложные срабатывания возможны и принимаются осознанно:**

| Запись | Нужная компания | Посторонняя, которая тоже исключится |
|---|---|---|
| Альфа | Альфа-Банк | Альфатех |
| Ozon | Ozon | Ozone Media |
| Сбер | Сбербанк | — (здесь работает как задумано) |

Поэтому:

- причина отказа всегда называет совпадение: «исключено по «Альфа»: Альфатех»;
- на фронте у поля исключённых компаний — подсказка: «Исключаются все компании, чьё название начинается с
  введённого. Например, «Сбер» исключит Сбербанк и СберМаркет, но «Альфа» исключит и Альфатех. Пишите название
  полнее, если нужно точнее.»

Ребрендинг с полной сменой названия (Mail.ru → VK) и разные языки (Яндекс / Yandex) правилом не ловятся:
пользователь вписывает все нужные названия сам. Домен сайта для сопоставления не используется (ложные
срабатывания, решение 06.11.2026).

## Компания не указана

Компания скрыта или не названа (анонимная вакансия HH, запись без компании в любом источнике) → «неизвестно» →
«Подходит» с меткой «не проверено».

Если в тексте сказано про NDA («компания под NDA», «название раскроем на интервью»), ставится метка «NDA»:
- компании в поле нет → «неизвестно», метка «NDA» объясняет почему;
- в поле есть компания (обычно агентство) → сравнивается она, метка «NDA» показывает, что настоящий работодатель
  скрыт.

## Работодатель из текста и агентства

- Работодателя из текста («ищем в команду …») не извлекаем: много ложных срабатываний, а при NDA его нет вовсе.
- Если вакансию публикует кадровое агентство, сравнивается название агентства. Исключить само агентство можно
  его названием.
- **Будущая функция (не реализуется):** определять, что вакансию опубликовало агентство, и показывать это меткой.

## Версии

Название компании из ленты и из карточки одного источника — изменение во времени: берётся новое. Если разные
источники называют компанию по-разному, исключение проверяется по каждому названию; совпало хоть одно и не
совпало другое → «возможно» по общему правилу.
