Макеты: канвас «Макеты hh-search-prototype: новый фронт» — https://claude.ai/artifact/6rVgMUDYixTPJJpFSPPZbs
(артборды 8·0–8п, палитра 5 «Чернила и маркер»). Утверждены 04.11.2026.

## Ветки

- База — долгоживущая ветка `rebuild` (`feodal01/job-harness`). В `main` не вливаем.
- Работа идёт в `claude/frontend-rebuild` от `origin/rebuild`; каждый этап — отдельный PR в `rebuild`.

## Подход

Фронт остаётся без сборки: статические файлы в `src/web/static`, их раздаёт FastAPI и они
попадают в wheel плагина. Классы макетов выросли из текущей вёрстки (`app-header`,
`page-heading`, `table-wrap`, `workspace`…), поэтому это эволюция, а не переписывание:
этап за этапом меняем стили, разметку и тексты экрана, сохраняя маршруты `#/…` и API.

- `tokens.css` — цвета, шрифт, радиусы, фокус палитры 5; `app.css` пользуется только токенами.
- Общий словарь (этапы, соответствие, статусы запусков, форматы дат и денег) — один модуль
  `vocabulary.js`, а не строки по всему `app.js`.
- Большой `app.js` по мере переделки режется на файлы по экранам; общий код — `api`, `el`, `$`.
- Доступность из макетов — часть каждого этапа: `:focus-visible`, `aria-current`,
  `aria-pressed`, `label for`, цели ≥ 44 px, информация не только цветом.

## Чего нет в бэкенде (макеты это помечают)

- Правила источников: режим «автоматически по местам», типы, «только выбранные компании»,
  исключения, автоподключение новых, счётчики по типам. Сейчас бриф хранит список `sources`.
- Архив, дублирование, переименование и удаление брифа (8а «⋯», 8п).
- Вход по ссылке на почту и провайдеры кроме GitHub/Google (8·0) — рисуем только то, что
  отдаёт `/auth/providers`.
- Массовое изменение этапа (8п) — пока циклом по PATCH.

## Вход обязателен (решено 05.11.2026)

Веб-приложение закрыто экраном входа 8·0: `GET /` без действующей сессии отвечает 303 на `/auth`,
`/auth` с сессией — 303 на `/`; открытая вкладка уходит на вход, когда сессия кончается или
пользователь выходит. Если проверить сессию не удалось (нет сети до Supabase), приложение тоже
закрыто — экран входа показывает причину и «Повторить». REST API и MCP не закрываются: у MCP свой
`authorize`, а каталог компаний и так требует входа.

На экране входа — только провайдеры из `/auth/providers`: первые три кнопками (последний
использованный — первым, с меткой «в прошлый раз»), остальные под «Другие способы · N».
Входа по ссылке на почту нет, пока его нет в бэкенде.
